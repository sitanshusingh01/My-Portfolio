Projects

Projects framed by problem, approach, and impact.

01 AI Powered Plastic Pollution Monitoring

PlasticNet AI

Problem: Dal Lake in Srinagar deals with ongoing plastic pollution, and there was no quick way to turn a photo of the shoreline into a number anyone could act on.

Approach: I built PlasticNet AI, a full stack platform that runs a semantic segmentation model (I tried Fast-SCNN, ENet, BiSeNetV2, and MobileNetV2Seg) on uploaded images, with a FastAPI backend and a React frontend.

Impact: Each upload returns a coverage percentage, a visual overlay, and region stats, and the platform also maps monitoring zones with GeoJSON and risk scoring so cleanup can be prioritized.

Python FastAPI React Deep Learning
Live Demo GitHub
02 Operations Analytics

Delivery Performance Analysis for a Multi Zone Food Platform

Problem: Delivery performance data across zones, shifts, and riders is hard to read at a glance, so it is easy to miss where late deliveries are actually piling up.

Approach: I analyzed close to 50,000 simulated delivery records with Python and Power BI, building drill downs by zone, time of day, and rider.

Impact: That showed two zones accounted for a disproportionate share of late evening deliveries, so I recommended shifting rider allocation to those windows.

Python Excel Power BI
Live Website GitHub
03 Sales Analytics

Customer and Sales Analysis for an Online Retailer

Problem: The category and pricing team needed to know which customer segments actually responded to discounts, based on real purchasing behavior.

Approach: I used SQL joins and window functions across roughly 20,000 transaction records to build customer summaries, then segmented customers in Python by spend and frequency.

Impact: I built a Power BI and Excel view for the category and pricing team that highlighted which customer segments were most sensitive to discounting.
